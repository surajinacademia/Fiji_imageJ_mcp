# Fiji MCP v0.2.0 Universal Fiji Gateway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the exact 13-tool standard and 15-tool trusted contracts over stdio while dynamically discovering, describing, and safely routing the installed Fiji catalog through typed converters and generation-bound session objects.

**Architecture:** Four independent catalog adapters produce canonical registrations and stable IDs. A fail-closed metadata normalizer and explicit converter registry determine eligibility. Worker operations own Java interaction and session state; thin public service methods own only strict request/response models and coordinator dispatch. One central registry is the only code allowed to register FastMCP tools.

**Tech Stack:** FastMCP 2.14.x, MCP Python types, Pydantic 2.11.x, PyImageJ 1.8.x, SciJava services, ImageJ1 APIs, NumPy, Pillow, pytest, Hypothesis, and real Fiji.

## Global Constraints

- Finish the runtime-foundation phase gate before starting.
- Preserve every authoritative registration unless its complete canonical tuple is byte-identical to another registration.
- Search display labels are never identities. Every describe/execute call requires both `command_id` and `catalog_fingerprint`.
- Unknown identity metadata is marked `identity_stability: installation`; unknown prerequisites, converter support, headless behavior, or completion behavior fail closed.
- A converter conflict is an error. Never silently choose the first matching converter.
- Unregistered Java values return `UNSUPPORTED_TYPE`; never stringify them as a successful typed result.
- Image IDs are never silently evicted. Immutable table and opaque-object handles use bounded pinned LRU retention.
- `run_plugin` invokes the exact registration; it never manufactures macro source.
- Standard `run_plugin` has no `raw_options` property in its schema. Trusted `run_plugin` may expose bounded raw options.
- Tool annotations and output schemas are release contracts.
- Every worker operation emits declared and reconciled effects with honest completeness.
- Delete old modules only after their replacement unit, stdio, and real-Fiji tests pass.
- For every task, run its listed focused pytest command immediately after adding the new test and confirm the intended missing-behavior failure; rerun the same command after implementation and confirm it passes.
- Every early real-Fiji catalog/converter probe runs through the Plan 01 spawned-worker harness. No integration test imports PyImageJ/JPype in pytest; each asserts `"jpype"` and `"imagej"` remain absent from parent `sys.modules` and uses worker PID/identity evidence to prove only the spawned child initialized Fiji.

`NativeImageToolResult[T]` contains `structured: ToolSuccess[T]`, private `content: bytes`, and a validated PNG/JPEG `media_type`; its `to_mcp_result()` constructs native MCP image content without serializing bytes, lease metadata, descriptors, or paths into `structuredContent`. Worker failures are converted from `FijiMcpError` into `ErrorToolResult`. Only `capture_image` calls `dispatch_capture`, which delegates the complete lease/completion/consume lifecycle to `OperationCoordinator.execute_capture`; ordinary `dispatch_worker` has no payload side channel.

    menu_path: str | None
    argument: str | None

`default_present=False` requires `default_value is None`; `default_present=True, default_value=None` represents an authoritative explicit null. `choices=None` means no authoritative choice metadata was supplied, while `choices=()` means the source explicitly supplied an empty set. `java_type=None` and `role="unknown"` preserve absent authoritative metadata; normalization marks them conditional/unsupported and `ConverterRegistry` returns `UNSUPPORTED_TYPE` before calling any `ValueConverter.supports`. Unknown path/bounds metadata likewise fails closed rather than being inferred from labels.

```python
class SessionObjectSummary(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    kind: Literal["image", "table", "object"]
    object_id: str
    generation: int
    java_type: str
    retention: Literal["explicit_close", "pinned_lru"]
    estimated_bytes: int
    pinned: bool


class SessionRegistry:
    def __init__(
        self,
        *,
        generation: int,
        session_nonce: UUID,
        limits: EffectiveLimits,
    ) -> None: ...

    def register_image(self, java_object: Any, metadata: ImageSummary) -> ImageId: ...
    def require_image(self, image_id: ImageId) -> ImageRecord: ...
    def activate_image(self, image_id: ImageId) -> None: ...
    def close_image(
        self,
        image_id: ImageId,
        *,
        discard_changes: bool,
    ) -> CloseImageData: ...
    def snapshot_table(self, table: Any, *, source_operation_id: UUID) -> TableId: ...
    def page_table(
        self,
        table_id: TableId,
        *,
        offset: int,
        limit: int,
        columns: list[str] | None,
    ) -> ResultsTablePage: ...
    def register_opaque(self, value: Any, *, java_type: str) -> ObjectId: ...
    def require_compatible(self, object_id: ObjectId, *, java_type: str) -> Any: ...
    def usage(self) -> SessionUsage: ...
```

`SessionObjectSummary` validates that the handle prefix matches `kind` and that its encoded generation matches `generation`.
