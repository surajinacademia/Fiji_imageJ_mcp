# fiji-mcp-server v0.1.2

- **PyPI README images:** demo screenshots now use absolute GitHub `raw` URLs so they display on [pypi.org](https://pypi.org/project/fiji-mcp-server/) (relative paths are not served by PyPI).

- **Macro templates:** larger catalog (channels, Z-project, stack tools, plugin entry points, extra filters).
